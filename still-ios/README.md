# Still for iPhone and iPad — development candidate

This separate native project starts from the published Still source at `bd515492a4849b670a8205fd2feb89d11d07b665`. It does not change the existing private website. The release dossier is in sibling `../app-store-release/`.

**Shared code.** Everything in `dist/` and `tests/` except `native-runtime.js` and the generated `offline-assets.js` (plus iOS-only pages such as `privacy.html`, `help.html`, `licenses.html` and `notices/`) is copied from `../still/` by `node ../scripts/sync-shared.mjs` (or `npm run sync` at the repository root). Edit shared files in `../still/`, not here. `tests/native-adapter.test.mjs` and the native runtime are iOS-only.

**Unverified in a native build (2026-09-30):** the shared code now includes `pdf-compat.js` and `pdf-worker.mjs` (so PDF page view works on iOS 18, where PDF.js 6.3 needs newer built-ins) and a top-level `await` at app start. Both are standard for the `safari18` esbuild target, but run `npm run build` and a simulator check before relying on them.

**Not submission ready.** Full Xcode, simulator/device validation, publisher/support/territory/pricing decisions, signing and legal review are outstanding. Swift source parsing and macOS storage tests do not constitute an iOS build.

## Architecture
Capacitor 8.5.2 hosts the bundled reader in WKWebView at `capacitor://localhost`. No remote site, authentication or dynamic app updates are needed. Native Files selection uses WebKit's file-input integration; a custom Swift plugin handles durable storage and the iOS export sheet. WK caches are nonpersistent. Documents and preferences live in a protected Application Support vault. The native app requires iOS/iPadOS 18.0+ provisionally; SDK submission requirements must be verified with Xcode before release.

The vault uses immutable JSON objects, opaque filenames, a serial native queue and an atomic manifest swap for a multi-record transaction. Original PDFs are base64-encoded in source records. This favors a small inspectable implementation; large-library memory and bridge performance still require device measurements. Device backups may include the vault. Plain JSON exports are not encrypted. No app accounts, telemetry or custom cryptographic keys are present.

Preferences persist every 1.5 seconds during activity and on pause/background; document text is stored separately, not rewritten every word. An abrupt process kill can lose up to the last checkpoint interval. Corrupt/missing manifests fail closed and never silently initialize over existing objects.

Normal reading, pacing, paragraph review, PDF/EPUB import, citation controls, source anchors, notes and backups preserve the web app's behavior. The app adds text-file import, permanent trash deletion and erase-all controls. Browser testing validates the shared UI; native Files, backgrounding, accessibility and export need actual iOS checks.

## Develop and verify
Requires Node 24+, npm and full Xcode for iOS work. Do not use global developer-directory changes just to build this project; set `DEVELOPER_DIR` to the intended Xcode installation when necessary.

```
npm ci
npm test
npm run test:native-core
npm run sync
npm start
```

The browser preview is `http://127.0.0.1:4174` and uses separate test-only browser storage. The native vault is exercised only on an iOS runtime. `npm run sync` generates assets and refreshes the native project. Open `ios/App/App.xcodeproj` in Xcode, select a simulator and build. The bundle ID `com.example.still.development` is intentionally provisional. Do not distribute it.

For a simulator build after installing Xcode:

```
xcodebuild -project ios/App/App.xcodeproj -scheme App -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

Use a real device to verify lock-state file protection, file-provider import, export completion, memory pressure, VoiceOver, dynamic type, interruptions and recovery. Screenshots for the store must come from the actual app, not the browser preview.

## Release guard
`npm run check:release` deliberately fails until `release-facts.json` and the release dossier contain real reviewed facts. A populated JSON file is not sufficient evidence by itself. Do not change false fields just to pass the command. The policy pages are drafts generated by `scripts/legal-pages.mjs`; finalize that source once publisher facts and reviews exist.

## Security and dependencies
Runtime npm dependencies: Capacitor core/iOS 8.5.2. The Xcode Swift package uses the exact same version. Build tools are pinned by package-lock. `xcode`'s build-time uuid dependency is overridden to 11.1.1 to address GHSA-w5hq-g745-h8pq; project generation, parsing and sync were retested. Bundled PDF.js and WordNet do not appear in npm audit and have a separate license/advisory inventory.

The app removes Google Fonts, disallows remote app navigation, restricts script messages to the trusted main frame, blocks document HTML/script execution, uses a CSP and limits file/archive sizes. PDF eval is disabled; EPUB paths, headers and CRC checks are validated. These measures do not establish universal safety or replace device testing/independent review.

To update from the website: export its bookshelf backup, transfer the file through Files, then restore from the app's Bookshelf. Browser storage does not automatically migrate to the app.
